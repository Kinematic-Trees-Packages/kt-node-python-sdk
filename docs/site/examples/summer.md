# Summer reference package

The independently deployable Python `summer` package is the next plan goal. Until that acceptance gate passes, this page intentionally does not provide an untested installation or deployment command.

The target behavior is a process that reads numeric opaque payloads, produces a sum, and depends only on released runtime and SDK artifacts—not a `kt_robotics` source checkout.

Use the [minimal process](minimal-process.md) as the proven package-independent starting point.
